Simple usage, cache, session warmth, and idle tracking for Claude Code sessions with an animated Claude companion. Takes up only 1 row above the narrow chat input box.

---

### Features

* **Weekly usage** — Every 10%, Claude gets older with a longer beard.
* **5h usage** — Every 10%, Claude gets more tired and breathes heavier.
* **Warmth** — Every 10% of 1h (until the session goes cold), Claude gets colder until frozen.
* **Cache** — Every 10% of the 1 million token cache limit, Claude's backpack gets bigger.

> *Don't get your Claudes cold this winter. Let them cook.*

---

### Installation

Just prompt this to your Claude Code:

PRESENT IN ALL YOUR CLAUDE CODE SESSIONS
```bash
Install me this Claude Code mod to work in every chat I open: https://github.com/BambiTester/usage-buddy.git
```

PRESENT WHEN ENABLED IN A SESSION
```bash
Install me this Claude Code mod to work when I enable it in the chat with the command: https://github.com/BambiTester/usage-buddy.git
```
